# Later Support

Public URL: https://later-screenshots.dhairya911.chatgpt.site/support

## Screenshots are missing

Open iOS Settings → Apps → Later → Photos and allow the screenshots you want Later to use. Return to Later and pull down on the home list to refresh. With Limited Access, only the photos you select are available.

## Sharing an image to Later

Open an image's share sheet and choose Later. Wait for confirmation that the image was queued. Analysis continues in a system background session, and Later can retry the upload the next time the main app opens.

## Notifications are missing

Open iOS Settings → Notifications → Later and confirm notifications are allowed. Later intentionally does not send discovery reminders for completed, expired, duplicate, date-passed, or likely accidental items.

## Removing data

Later has no user account or cloud library. Delete individual items inside Later. If an item is linked to Photos, Later can ask iOS to delete the original as well. Deleting the app removes Later's local data subject to normal iOS and backup behavior.

When requesting help, include the app version and build number shown in Settings → Support. Do not send private screenshots unless they are necessary to explain the problem.
